Firewall Microproject

Created by 537_Lizel Rodrigues

Problem Statement

Many networks are vulnerable to unauthorized access and cyber threats. This project aims to implement a firewall to secure a network and monitor incoming and outgoing traffic.

Solution

We configured a firewall using Packet Tracer to control network access and protect against unauthorized connections. Rules are applied to allow or block specific traffic.

Features

  • Network security via firewall rules
  • Monitors and logs network traffic
  • Easy to demonstrate in Packet Tracer
  • Useful for small to medium networks

Outputs / Results

The firewall successfully blocks unauthorized access while allowing permitted traffic. Screenshots of Packet Tracer simulation show the firewall in action.
